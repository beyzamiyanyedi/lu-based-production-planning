# LU-Based Production Planning Tool

## Overview

This project was developed as part of a Linear Algebra course project to demonstrate the application of LU factorization to an industrial engineering production planning problem.

The application uses a linear system to model production quantities and provides an interactive dashboard for exploring production scenarios and machine utilization.

## Features

- Interactive product demand inputs
- Production quantity calculations using LU factorization
- Machine utilization and bottleneck indicators
- Production distribution visualizations
- Capacity versus usage comparisons
- Numerical sensitivity analysis
- Monte Carlo demand simulation
- Basic economic analysis

## Technologies

- Python
- NumPy
- SciPy
- Streamlit
- Matplotlib

## Project Structure

- `main.py` — Streamlit application

## How to Run

1. Clone or download this repository.

2. Start the application:

   `streamlit run main.py`

## Academic Context

Developed collaboratively as a Linear Algebra course project, exploring the practical application of LU factorization to production planning.
